# Grading definition examples

Definitions use one versioned envelope. See the [complete contract](../contracts/DEFINITIONS.md)
and its [valid/invalid example table](../contracts/DEFINITIONS.md#examples-and-errors).

The runnable JSON fixtures under `docs/contracts/v1/examples/` cover Python/C,
multiple languages, base/bonus/penalty, nested groups, feedback resources, file
artifacts, APIs, web inspection and AI/static checks. They are compiled in tests.
Old test_library/list-parameter examples were retired. Convert existing files with
the [explicit migration tool](../contracts/DEFINITIONS.md#legacy-definition-migration).
