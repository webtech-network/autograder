# AI batch assessment

`evaluate_ai_batch(criteria, submission, provider)` resolves selected AI
criteria's files with the shared file-selection policy, calls each evaluator's
`build_prompt(evaluation, **normalized_parameters)`, and sends one request to the
host provider. Full context files are separate from each criterion's scoped
assessment files.

It returns `dict[criterion_id, TestResult]` directly to the coordinator, which
passes it as `assessments` to grading. The grader uses the assessment for each AI
criterion ID; ordinary evaluators never receive AI results or provider clients. Results must exactly cover the
requested IDs. Repeated evaluator names and display labels do not collide.
Missing assessments fail grading without provider retries or zero-score fallbacks.

No selected AI criteria means no provider request. The provider is borrowed;
execution sessions, when needed by other criteria, remain owned by the run.

Implementation: `autograder/services/ai_batch.py`.
