# Assess criteria (with batched AI)

`assess_criteria(criteria, submission, session=..., ai=...)` in
`autograder/services/assessment.py` returns one validated `TestResult` per
criterion ID. It walks the compiled tree once (`CriteriaTree.get_all_tests`,
nested subjects before a holder's direct tests) and prepares each criterion with
the shared [file-selection policy](../contracts/FILES.md) and its typed
`EvaluationInput`.

- **Ordinary evaluators** run individually with an isolated copy of their
  canonical parameters (`assess_one`).
- **AI evaluators** are assessed together by `assess_many(criteria, provider,
  context_files=..., locale=...)`: it calls each evaluator's
  `build_prompt(evaluation, **parameters)`, sends one `AssessmentRequest(criterion_id,
  prompt)` per criterion to the host provider in a **single** `assess` call, and
  returns results keyed by criterion ID. A single AI criterion is a group of one;
  there is no separate single-item path.

`assess_many` owns provider-output validation and error mapping for every group
size. The provider must return exactly one `ProviderAssessment(criterion_id,
score, report)` per requested ID:

| Provider output | Failure |
|---|---|
| unknown or duplicate criterion ID | `INVALID_EVALUATOR_RESULT` (provider, retryable) |
| missing criterion ID (including an empty answer) | `MISSING_EVALUATOR_RESULT` (provider, retryable) |
| non-finite/out-of-range/boolean/text score, non-text report, wrong type | `INVALID_EVALUATOR_RESULT` (provider, retryable) |
| provider raises a non-`EvaluationError` | `PROVIDER_ERROR` (provider, retryable; detail only in logs) |
| provider raises `EvaluationError` | passed through unchanged |

Every failure is a required failure: the outcome has a null score and tree.
Nothing is retried, dropped or replaced by a zero. No selected AI criteria
means no provider call. Repeated evaluator types and duplicate display labels
remain distinct because only criterion IDs identify requests and results.

The provider is borrowed from `HostCapabilities.ai`; model, credentials and
deadline are host configuration (#376). Prompts name each criterion's selected
files, and the provider additionally receives every submitted file as context.

Scoring ([Grade](05-grade.md)) receives only the merged ID-keyed results. No
evaluator, grader constructor or execution accessor carries AI results.
