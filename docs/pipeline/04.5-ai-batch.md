# Step 4.5: Batched AI assessment

`AiBatchStep` collects selected AI criteria, resolves their assessment files with
the [shared file-selection policy](../contracts/FILES.md), and builds prompts.
The host-supplied assessment provider receives these prompts, the locale and all
submitted text as context. Scope does not establish a privacy or upload boundary.

One batch returns `Dict[criterion_id, TestResult]`. IDs must exactly cover the
requested criteria, including repeated evaluators and duplicate display names.
Missing assessments, invalid results and provider failures fail the required
assessment with null score/tree. There is no standalone provider fallback or
silent zero when a batch omits a result.

The grader supplies each precomputed result to `AiTestFunction.execute`. Static
runs do not call an AI provider; unused AI templates do not request one. Core
does not construct OpenAI clients, load environment files, read secrets or choose
a model. The concrete optional OpenAI provider lives in
`execution_host/openai_provider.py`; hosts can inject any provider implementing
the [assessment contract](../contracts/CAPABILITIES.md).
