# Structural analysis inside assessment

Structural parsing belongs to the static evaluator. There is no separate
pipeline step, structural-result artifact or grader-level AST cache.
`ForbiddenKeywordTest` parses only its selected sources with `parse_source`
during its own assessment; no AST state is shared across criteria or runs.
Its keyword support and custom-rule compilation for every allowed language are
checked by its own `validate_parameters` hook at compilation.

[The file contract](../contracts/FILES.md) defines supported source extensions,
explicit targets, scope, context, required inputs and changed-line semantics.
Documents and configuration remain context and are never parsed as source code.
Other checks do no AST work; unavailable parsing fails the required assessment.
