# Structural analysis inside assessment

Structural parsing now belongs to the static evaluator. There is no separate
pipeline step or structural-result artifact. `ForbiddenKeywordTest` parses its
selected sources lazily through `StructuralAnalysisCache`, created for one
`SubmissionGrader` traversal and keyed by source content and grammar.

[The file contract](../contracts/FILES.md) defines supported source extensions,
explicit targets, scope, context, required inputs and changed-line semantics.
Documents and configuration remain context and are never parsed as source code.
Other checks do no AST work; unavailable parsing fails the required assessment.

The next pipeline stage after optional AI batching is [Grade](05-grade.md).
