# Calculator examples

The five files under `criteria_examples/` are complete grading definitions,
from flat addition checks to weighted nested groups; the browser demo offers
them as presets. Student programs under `code_examples/` cover simple and
advanced calculators. See the [examples overview](../../README.md).

Check one and grade a calculator with it from the repository root, for example
`python -m execution_host.check examples/assets/input_output/criteria_examples/1_base_only_simple.json --language python --submission DIR`,
where `DIR` holds `simple_calculator.py` saved as `calculator.py`
([Test your rubric](../../../docs/author/testing.md)).
